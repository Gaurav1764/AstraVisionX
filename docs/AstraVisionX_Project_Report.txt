1. EXECUTIVE SUMMARY & WHAT WE HAVE DONE TILL NOW
--------------------------------------------------------------------------------
AstraVisionX is an enterprise-grade multimodal computer vision, explainable AI (XAI),
and conversational visual reasoning platform. It enables users to upload any visual 
medium (medical, scientific, industrial, or natural scenes), run dual-stage object 
detection and scene classification models, inspect visual interpretability heatmaps 
(Grad-CAM, SHAP, LIME), evaluate quantitative consensus metrics (IoU/Dice), receive 
decision boundary reliability assessments, interact with a synchronized multi-panel 
zoom/pan stage, and converse with a visually-grounded Multimodal AI assistant.

Key Milestones & System Features Completed:

1. Full-Stack Asynchronous Architecture:
   - High-throughput FastAPI asynchronous REST API backend with modular design.
   - In-memory thread-safe Session Manager with automatic 30-minute TTL expiry and
     on-demand caching for detections, classifications, and XAI overlays.
   - Clean, modern, responsive glassmorphic dashboard (Vanilla HTML5, CSS3, ES6+ JS).

2. Dual-Engine Deep Learning Pipeline:
   - Fine-Grained Object Detection: Integrated Ultralytics YOLOv8 trained on Open 
     Images V7 (601 object categories, e.g., yolov8s-oiv7.pt) for accurate object
     localization, bounding boxes [xmin, ymin, xmax, ymax], and confidence metrics.
   - Global Scene Classification: Integrated Vision Transformer (ViT-Base-Patch16-224 
     via timm) and ResNet18 CNN backbone for global context and deep feature extraction.
   - Automated Uncertainty & Out-of-Distribution Handling: Dynamic relabeling of 
     sub-threshold predictions (flagging "⚠️ Uncertain match" or "⚠️ General-purpose model").
   - Color Space Optimization: Automatic BGR/RGB array normalization for Ultralytics YOLO 
     inference, eliminating color distortion artifacts.

3. Triple-Method Explainable AI (XAI) & Consensus Suite:
   - Grad-CAM (Gradient-weighted Class Activation Mapping): PyTorch backward gradient
     and activation hook engine with OpenCV colormaps and Gaussian boundary smoothing.
   - SHAP (Shapley Additive exPlanations): Feature attribution evaluating positive 
     contributions vs. negative suppressions using diverging colormaps.
   - LIME (Local Interpretable Model-agnostic Explanations): Superpixel segmentation 
     (Quickshift/SLIC) with local perturbation linear attributions.
   - Region-Targeted / Per-Detection XAI: Ability to compute Grad-CAM, SHAP, and LIME 
     specifically cropped and padded (20% spatial context) for any individual detected object.
   - Multi-Method Consensus & Agreement Metrics: Automated quantitative overlap calculation 
     (Pairwise and Global Intersection over Union / IoU and Dice similarity coefficients) 
     across Grad-CAM, SHAP, and LIME salient binary masks.

4. Confidence & Decision Boundary Reliability Breakdown:
   - Raw Top-1 Confidence Metric and Top-5 alternative prediction distribution.
   - Decision Boundary Margin: Evaluates the delta between Rank 1 and Rank 2 predictions
     (Decisive Separation ≥ 50%, Moderate Separation ≥ 20%, Narrow Boundary < 20%).
   - Holistic Decision Reliability Badge: Categorizes output into High Reliability, 
     Moderate Reliability, or Potential Out-of-Distribution/Uncertain.

5. Interactive Viewport & Bi-Directional Linking:
   - GPU-accelerated CSS transform scaling, pan, and bounding box coordinate mapping.
   - Bi-directional selection: Clicking any detection in the table or bounding box on 
     the image stage focuses the target object, zooms with context padding, and dims 
     background elements.
   - Dynamic In-Place XAI Overlays: Seamless tabbed switching between Grad-CAM, SHAP, 
     and LIME overlays with live overlay toggle switch and color-coded confidence badges.
   - Keyboard navigation (Enter/Space) and prefers-reduced-motion accessibility compliance.

6. Resilient Multimodal Conversational Assistant (Astra AI):
   - Google Gemini 3.x Multimodal LLM integration with visual context grounding.
   - Attached Image + Context Grounding: Directly passes image byte payloads alongside 
     structured session findings (detections, classifications, and XAI maps) into Gemini.
   - Multi-Key Load Balancer & Multi-Model Cascade Failover Engine (gemini_service.py):
     Aggregates keys from .env and api_keys.txt and automatically cascades across candidate 
     models in optimized priority order (gemini-3.7-flash, gemini-3.1-flash-lite, 
     gemma-4-26b-a4b-it, gemma-4-31b-it, gemini-3.8-flash, gemini-3.5-flash), eliminating 
     503 high-demand and 429 rate-limit downtime.
   - Context-Grounded Prompting: Injects YOLO detections, ViT top-5, XAI metrics, 
     confidence margin, and reliability status into system prompts.
   - Interactive Quick Prompt Chips for rapid one-click visual inquiries.
   - Web Speech API Two-Way Audio: Voice input (SpeechRecognition) + Text-to-Speech (SpeechSynthesis).

7. Automated PDF Report Dossier Generation:
   - ReportLab PDF generator compiling comprehensive diagnostic/analytical reports with 
     image plates, detection tables, classification rankings, XAI explanation summaries, 
     confidence margin breakdowns, and formal disclaimers.

8. Category Filtering & Hierarchical Detection Suite:
   - Comprehensive taxonomy mapper (astravisionx/models/category_map.py) mapping all 601
     OIV7 classes into Persons, Vehicles, License Plates, Clothing, Animals, and Other.
   - Bounding-box containment linking (_ioa calculation) attaching clothing/body parts to 
     parent persons and license plates to parent vehicles with nested visual tags.
   - Interactive UI filter chips with real-time synchronized counts, search query text filter,
     confidence range slider, and switchable Dim (12% opacity) vs. Hide canvas modes.
   - Grounded filter context propagation to Astra AI conversational assistant.

9. Comprehensive Testing & Verification Suite:
   - Pytest unit and integration test suite (tests/test_confidence.py, tests/test_category_filter.py) 
     validating confidence score bounds [0.0, 1.0], category grouping, parent-child linking, 
     demographic estimation rules, and endpoint contracts.
